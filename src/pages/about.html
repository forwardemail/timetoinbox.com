Who runs this site

TimeToInbox is run by the team behind Forward Email, an open-source email service for custom domains. Forward Email measures and publishes its own time to inbox results, and this site explains what those numbers mean and how to measure the same thing for your own mail. Start with the time to inbox overview.

The site has no ads and nothing to sign up for. Where Forward Email is relevant, the pages link to it, and every link to a Forward Email page or source file goes to the real page.

How the content is written

  • Facts and numbers link to a primary source: an RFC, vendor documentation, or the Forward Email source code.
  • Descriptions of Forward Email's monitor come from reading its code in the forwardemail.net repository.
  • Live measurements are not copied onto this site because they change every few minutes. The pages link to the live results instead.

Contact and corrections

Found a mistake or a broken link? Open an issue on GitHub or send a pull request. Each page has an "Edit this page on GitHub" link in the footer that opens its source file.

For questions about Forward Email itself, start with the Forward Email FAQ or email support@forwardemail.net. To report a security issue with this site, email security@forwardemail.net or see /.well-known/security.txt.

Source code

The site is plain HTML and CSS generated by a small Node.js script with no dependencies. The source is public at github.com/forwardemail/timetoinbox.com, and GitHub Pages serves the files from the repository.

Privacy summary

TimeToInbox does not use cookies, analytics, trackers, JavaScript or third-party resources. Requests pass through Cloudflare, which processes visitor IP addresses, on their way to GitHub Pages. Read the full privacy policy.

Files for crawlers and AI agents

  • /llms.txt: a short index of the site for language models.
  • /llms-full.txt: the full text of every page in Markdown.
  • /sitemap.xml and /robots.txt: all crawlers, including AI crawlers, are allowed.
  • Every page has a Markdown copy at the same path with a .md suffix, for example /faq.md. The home page copy is /index.md.
